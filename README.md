# Aviutl2-QRCode
 
QRコードの生成ができるスクリプトです。
 
---
 
## 導入方法
 
1. `QRCode.obj2` を、AviUtl2 のプレビュー画面へドラッグ＆ドロップします。
2. **[カスタムオブジェクト] ＞ QRコード** から適用できます。
---
 
## 設定項目一覧
 
| 項目名 | 種別 | 設定範囲 | 初期値 | 説明 |
| :--- | :---: | :---: | :---: | :--- |
| **サイズ** | トラックバー | 1 〜 100 | 10 | ドットの基本サイズを指定します。 |
| **余白** | トラックバー | 0 〜 20 | 4 | QRコード周囲の余白の広さを指定します。 |
| **誤り訂正** | リスト選択 | L / M / Q / H | L | データの誤り訂正レベルを選択します。レベルが高いほど復元力が上がりますが、QRコードが大きくなります。 |
| **形状** | リスト選択 | 四角 / 円 / 角丸 | 四角 | QRコードを構成するデータドットの形状を選択します。ファインダーパターン（位置検出用の正方形）は常に四角で描画されます。 |
| **テキスト** | 文字列 | 任意文字列 | `https://example.com` | QRコードに埋め込むテキストやURLを指定します。 |
| **前景色** | カラー | — | `#000000` | QRコードのドット部分の色を指定します。 |
| **背景色** | カラー | — | `#ffffff` | 背景の色を指定します。「背景透明」が有効な場合は無視されます。 |
| **背景透明** | チェックボックス | ON / OFF | OFF | チェックを入れると背景を透明にします。 |
| **角丸強度** | トラックバー | 0 〜 100 | 30 | 形状で「角丸」を選択した際のドットの丸みの強さを指定します。 |
